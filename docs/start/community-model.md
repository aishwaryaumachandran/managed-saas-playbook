# 02 · Community Operating Model

A simple operating model for running the community.

::: info TL;DR
Organize into working groups per design area, **link** the official docs
rather than rewriting them, reuse accelerators, and run the WAF SaaS
assessment as the standard intake scorecard.
:::

## Working structure

- **Working groups** — one per design area (tenancy, identity, data, billing, governance, DevOps, incident management, AI-in-SaaS).
- **Curated link set** — link the official docs rather than rewriting them (see [Sources](../sources.md)).
- **Cadence** — run the WAF SaaS assessment as the intake scorecard for every solution review.

## Fast-start path for new members

1. Understand SaaS and multitenancy
2. Learn the design methodology and the five principles
3. Explore the [tenancy model diagrams](../design/tenancy-decision-guide.md)
4. Run the WAF assessment
5. Plug into Marketplace delivery

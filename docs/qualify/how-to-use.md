# 03 · How to Use This Guide

A board-shareable reference for evaluating and shaping Managed SaaS
opportunities. It pairs with
[What Is Managed SaaS](../start/what-is-managed-saas.md) for definitions and the
curated [Sources](../sources.md). Use this guide to answer three questions consistently:

1. **Does this opportunity qualify as Managed SaaS?**
2. **How should we shape it** (tenancy, data, capacity)?
3. **What best practices and governance keep it healthy over time?**

Grounded in the Well-Architected Framework (WAF) SaaS workload guidance and the
Azure Architecture Center multitenancy guidance. 

## Who uses what

- **Reviewers** run the [Qualification Scorecard](scorecard.md) as an intake
  scorecard before committing effort.
- **Architects** use the [tenancy patterns](../design/tenancy-models.md), the
  [data patterns](../design/data-patterns.md), and the
  [capacity model](capacity.md) to shape the solution.
- **Leads and sponsors** use the [governance model](../govern/governance.md) to
  keep the portfolio consistent.
